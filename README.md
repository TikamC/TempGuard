# TempGuard — фоновый контроль температуры (Windows 10/11)

Каждую секунду опрашивает **все** температурные датчики (CPU, GPU, RAM/DIMM, SSD/NVMe/HDD,
материнская плата, контроллеры, батарея и т. д.) через библиотеку LibreHardwareMonitor.
Если какой-либо датчик ≥ 92 °C — в верхнем углу экрана появляется красная плашка со списком
перегретых датчиков и их температурой. Когда температура падает ниже 90 °C (92 − 2 °C гистерезис,
чтобы плашка не мигала), индикация исчезает.

## Сборка

1. Установите [.NET SDK 10](https://dotnet.microsoft.com/download) (для .NET 8 замените
   `net10.0-windows` на `net8.0-windows` в `TempGuard.csproj`).
2. В папке проекта:

```powershell
dotnet publish -c Release -r win-x64 --self-contained -p:PublishSingleFile=true -o publish
```

Готовый `publish\TempGuard.exe` можно копировать куда угодно. Если одиночный exe по какой-то
причине не запускается — уберите `-p:PublishSingleFile=true`.

## Запуск

- Нужны **права администратора** (манифест запросит UAC) — без них большинство датчиков не читаются.
- Окна нет, программа живёт в трее (иконка щита). ПКМ по иконке: сторона показа (справа/слева), выход.
- Запуск сразу слева: `TempGuard.exe --left`.
- Плашка не принимает кликов (клики проходят сквозь неё) и не забирает фокус.

## Автозапуск с правами администратора (без UAC-окна при входе)

```powershell
schtasks /Create /TN "TempGuard" /TR "\"C:\Tools\TempGuard\TempGuard.exe\"" /SC ONLOGON /RL HIGHEST /F
```

Удалить: `schtasks /Delete /TN "TempGuard" /F`

## Настройки

В начале `Program.cs`, класс `Config`: порог (`ThresholdC`), гистерезис, период опроса, отступ.

## Ограничения

- Показываются только те датчики, которые реально отдаёт ваше железо; у части ноутбуков/плат
  (особенно RAM) их может не быть.
- Поверх полноэкранных игр в «эксклюзивном» режиме плашка может не отображаться
  (в режиме «в окне без рамок» — работает).
- Датчики «Distance to TjMax» / «Thermal Margin» намеренно игнорируются: это запас до предела,
  а не температура.
